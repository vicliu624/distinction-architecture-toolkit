# Prompt: Final Owner Migration Plan

Create an implementation plan that moves current responsibilities directly to final owners.

The plan must include:

- files to create
- files to modify
- files to delete
- design patterns involved
- migration order
- checker updates
- validation commands
- rollback risks

Forbidden:

- transitional UI layer
- migration adapter
- archive-only source root
- wrapper that will be removed later
- moving old files wholesale without decomposition
